# 港邊釣夢 (`pg-seacast`)

魚圖鑑、漁場天氣、裝備升級，以及張力收線的港邊釣魚小品。

類型：**海釣養成** · 系列：懷舊

## 遊玩

純 HTML／CSS／JavaScript（無 build）。在 Playgrounds 畫布或 go 純玩模式開啟。

- 選 **防波堤／紅樹林／外海礁**，看天候換餌與裝備
- **拋竿**後等咬餌，**按住收線**；張力進入綠區時魚會靠近
- 集齊 **六種魚**完成圖鑑即通關；季節與體力有限

## 開發

```bash
npx vitest run
```
